
MINDSPACE

MINDSPACE é uma plataforma web para conectar pacientes, profissionais de saúde e voluntários, permitindo agendar, visualizar e cancelar consultas de forma simples.

Funcionalidades
Landing page — apresentação do projeto e ponto de entrada do site
Login — acesso de usuários à plataforma
Consultas — agendamento e cancelamento de consultas
Especialidades — visualização das áreas médicas disponíveis
Profissionais — listagem e perfis dos profissionais de saúde
Voluntários — área destinada aos voluntários da plataforma
Nav — componente de navegação compartilhado entre as páginas
Estrutura do projeto
mindspace/
├── consultas/
├── especialidades/
├── landingpage/
├── login/
├── nav/
├── profissionais/
└── voluntarios/

Cada pasta contém os arquivos HTML, CSS e imagens referentes àquela seção do site.

Tecnologias utilizadas
HTML5
CSS3
Como executar o projeto
Clone este repositório ou baixe os arquivos.
Abra o arquivo index.html da seção desejada (por exemplo, landingpage/index.html) diretamente no navegador.
